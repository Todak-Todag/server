# 01. 서비스 희망 일정 수정

| 항목     | 내용                                                  |
|--------|-----------------------------------------------------|
| Method | `PATCH`                                             |
| URL    | `/api/v1/service-preferences/{servicePreferenceId}` |
| 사용자    | 퇴원예정자                                               |
| 카테고리   | 수정                                                  |
| 테이블명   | `p_care_plan_service_preferences`                   |

## 설명

퇴원 예정자가 병원 담당자의 권고 서비스를 수락하여 희망 날짜와 시간대를 입력한다. Care Plan이 아직 확정되기 전 단계에서 사용하는 API다.

## 비즈니스 규칙

- 해당 `servicePreferenceId`가 속한 Care Plan의 `status`가 `UNDER_REVIEW`인 경우에만 수정할 수 있다.
- 본인(퇴원 예정자)의 Care Plan에 속한 희망 일정만 수정할 수 있다.
- 요청자의 `userId`와 `role`은 `X-User-Id`/`X-User-Role` 헤더(Gateway가 인증 후 주입)로 확인한다.

> ✅ 확정 (2026-09-04, 팀 확인 완료):
> - 요청자는 퇴원 예정자(`PATIENT`)만 가능하다 (`X-User-Role` 예시값 `SERVICE_PROVIDER`는 원본 스펙의 오기였음).
> - Method/URL은 `PATCH /api/v1/service-preferences/{servicePreferenceId}`로 확정한다 (전체 필드가 아닌 희망 일정 자체를 갱신하는 성격상 `PATCH` 채택).
> - 404 에러 코드는 `CARE_PLAN_SERVICE_NOT_FOUND`를 재사용하지 않고 `SERVICE_PREFERENCE_NOT_FOUND`를 신규 등록해 사용한다 (`servicePreferenceId` 미존재와 `CarePlanService` 미존재를 구분하기 위함).
> - Care Plan이 `UNDER_REVIEW` 상태가 아닐 때는 `409 Conflict`(`SERVICE_PREFERENCE_NOT_ALLOWED`, 등록 API와 동일 코드 재사용)를 반환한다.
> - `preferredDate` 검증은 등록 API와 동일하게 Care Plan의 `startDate`~`finishDate` 범위를 벗어나면 `400`(`SERVICE_PREFERENCE_DATE_OUT_OF_RANGE`)을 반환한다.

## Request

| key                 | 설명      | value 타입     | 위치            | 제약사항                   | Nullable | 예시                                     |
|---------------------|---------|--------------|---------------|------------------------|----------|----------------------------------------|
| X-User-Id           | 요청자 Id  | UUID         | Header        | -                      | X        | `4fa85f64-5717-4562-b3fc-2c963f66afa6` |
| X-User-Role         | 요청자 권한  | String(ENUM) | Header        | Gateway가 인증 후 주입, 필수   | X        | `PATIENT`                              |
| servicePreferenceId | 희망일정 ID | UUID         | Path Variable | -                      | X        | `3fa85f64-5717-4562-b3fc-2c963f66afa6` |
| preferredDate       | 희망 날짜   | LocalDate    | Body          | -                      | X        | `2026-09-10`                           |
| preferredTimeSlot   | 희망 시간대  | String(ENUM) | Body          | `MORNING`, `AFTERNOON` | X        | `MORNING`                              |

## Response

| key                 | 설명      | value 타입 | 옵션 | Nullable | 예시                                     |
|---------------------|---------|----------|----|----------|----------------------------------------|
| servicePreferenceId | 희망일정 ID | UUID     | -  | X        | `3fa85f64-5717-4562-b3fc-2c963f66afa6` |

## Status

| status | response content                  |
|--------|-----------------------------------|
| `200`  | 서비스 희망 일정 수정 성공                   |
| `400`  | Validation 실패                     |
| `403`  | 권한 없음                             |
| `404`  | 존재하지 않는 `servicePreferenceId`     |
| 409    | Care Plan이 UNDER_REVIEW 상태가 아닌 경우 |
