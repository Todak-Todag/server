# 04. 서비스 일정 취소

| 항목 | 내용 |
| --- | --- |
| Method | `PATCH` |
| URL | `/api/v1/service-schedules/{serviceScheduleId}/cancel` |
| 사용자 | 퇴원예정자 |
| 카테고리 | 수정 |
| 테이블명 | `p_service_schedules`, `p_schedule_outbox_events` |

## 설명

퇴원 예정자가 예정된 서비스 일정을 취소한다.

## 비즈니스 규칙

- 접근 권한은 `@PreAuthorize("hasRole('PATIENT')")`로 제한하며, 요청자의 `userId`는 `@AuthenticationPrincipal UserContext user`로 주입받는다.
- 일정 시작 **24시간 전까지**만 취소할 수 있다. 위반 시 **`409`** (`SERVICE_SCHEDULE_CANCEL_DEADLINE_EXCEEDED`).
- 본인에게 배정된 서비스 일정만 취소할 수 있다.
  - `servicePreferenceId`를 기준으로 **care-plan-service Internal API**(`GET /internal/v1/service-preferences/{servicePreferenceId}/care-plan`)를 호출해 `carePlanId`/`finishDate`/`patientId`를 조회하고, `patientId`와 요청자 `userId`를 대조한다 (03번과 같은 API 재사용, 여기서는 `patientId`만 사용).
  - 호출은 Facade에서 **DB 트랜잭션 밖으로** 수행한다.
- **취소 가능 상태는 `SCHEDULED`와 `RESCHEDULING`이다.** 변경 요청 후 재매칭을 기다리는 중(`RESCHEDULING`)에도 취소할 수 있다.
- 취소 시 `status`는 `CANCELED`로 변경되고 `cancelReason`(필수), `canceledAt`이 기록된다.
- 이미 완료(`COMPLETED`)/부도(`NO_SHOW`)/변경완료(`CHANGED`)/취소(`CANCELED`)된 일정은 `409 CONFLICT`를 반환한다.
- **취소로 케어플랜의 마지막 일정까지 결말이 나면 같은 트랜잭션에서 `CarePlanCompleted`가 아웃박스에 적재된다.** 취소로 끝나는 케어플랜은 07번(수행 결과 등록) 경로로는 영원히 완료 처리되지 않기 때문이다 (11번 문서 참고).

## Request

| key | 설명 | value 타입 | 위치 | 제약사항 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- | --- |
| serviceScheduleId | 취소할 서비스 일정 ID | UUID | Path Variable | 존재하는 서비스 일정이어야 함 | X | `3fa85f64-5717-4562-b3fc-2c963f66afa6` |
| cancelReason | 취소 사유 | String | Body | `@NotBlank` | X | `개인 사정으로 취소합니다` |

> 요청자의 `userId`/`role`은 Request 표에 헤더로 명시하지 않고 `@AuthenticationPrincipal UserContext user`로 주입받는다.

## Response

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| serviceScheduleId | 취소된 서비스 일정 ID | UUID | - | X | `3fa85f64-5717-4562-b3fc-2c963f66afa6` |
| canceledAt | 취소 처리 일시 | LocalDateTime | - | X | `2026-08-27T10:00:00` |

**Example**

```jsx
// 성공
{
  "success": true,
        "code": 200,
        "message": "서비스 일정 취소 성공",
        "data": {
  "serviceScheduleId": "3fa85f64-5717-4562-b3fc-2c963f66afa6",
          "canceledAt": "2026-08-27T10:00:00"
}
}

// 실패
{
  "success": false,
        "code": "SERVICE_SCHEDULE_INVALID_STATUS_FOR_CANCEL",
        "message": "취소할 수 없는 상태의 서비스 일정입니다.",
        "details": {
  "reason": "취소할 수 없는 상태의 서비스 일정입니다."
},
  "timestamp": "2026-08-27T10:00:00Z"
}
```

## Status

| status | ErrorCode | response content |
| --- | --- | --- |
| `200` | - | 취소 성공 |
| `400` | `INVALID_PARAMETER` | `cancelReason` 누락/공백 등 Validation 실패 |
| `403` | `AUTH_FORBIDDEN` | 본인 소유가 아니거나, 존재하지 않는 서비스 일정 (리소스 존재 여부 비노출) |
| `409` | `SERVICE_SCHEDULE_CANCEL_DEADLINE_EXCEEDED` | 취소 가능 시간(시작 24시간 전)이 지남 |
| `409` | `SERVICE_SCHEDULE_INVALID_STATUS_FOR_CANCEL` | 취소할 수 없는 상태(이미 완료/부도/변경완료/취소됨) |
