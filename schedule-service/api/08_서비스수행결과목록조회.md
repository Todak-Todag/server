# 08. 서비스 수행 결과 목록 조회

| 항목 | 내용 |
| --- | --- |
| Method | `GET` |
| URL | `/api/v1/service-results` |
| 사용자 | 퇴원예정자, 서비스 제공자 |
| 카테고리 | 검색 |
| 테이블명 | `p_care_plan_service_results` |

## 설명

퇴원 예정자 또는 서비스 제공자가 자신과 관련된 서비스 수행 결과 목록을 조회한다.

## 비즈니스 규칙

- 퇴원 예정자는 **자신이 받은** 서비스의 수행 결과만, 서비스 제공자는 **자신이 제공한** 서비스의 수행 결과만 조회할 수 있다.
- 정렬은 최신순/오래된순이 가능하다 (기본값 `createdAt,DESC`).
- 소유권 필터링은 레코드별 개별 검증이 아니라 **ID 목록 기반 조회** 방식을 따른다.
    - **서비스 제공자가 조회하는 경우**: provider-service Internal API(`GET /internal/v1/service-offerings?providerId=`)에 요청자 `userId`를 전달하여 담당하는 모든 `serviceOfferingId` 목록을 조회한다.
    - **퇴원 예정자가 조회하는 경우**: care-plan-service Internal API(`GET /internal/v1/service-preferences?patientId=`)에 요청자 `userId`를 전달하여 담당하는 모든 `servicePreferenceId` 목록을 조회한다.
    - ⚠️ 확인 필요 (신규): `p_care_plan_service_results`에는 `service_preference_id`/`service_offering_id` 컬럼이 없다 (`schedule-service.md` 2장 도메인 모델 기준 — 이 테이블은 `service_schedule_id`만 FK로 가진다). 따라서 조회한 ID 목록으로 곧바로 `p_care_plan_service_results`를 필터링할 수 없고, `p_service_schedules`와 `service_schedule_id`로 **조인**한 뒤 `p_service_schedules.service_preference_id IN (:ids)` 또는 `service_offering_id IN (:ids)` 조건을 적용해야 할 것으로 보인다. 두 테이블 모두 schedule-service 소유라 DB 조인 자체는 MSA 원칙에 위배되지 않지만, 이 조인 관계가 문서에 명시되어 있지 않아 확인이 필요하다.

## Request

| key | 설명 | value 타입 | 위치 | 제약사항 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- | --- |
| page | 페이지 번호 | Integer | Query Parameter | 음수 불가능 | O | `0` |
| size | 페이지 크기 | Integer | Query Parameter | `10`, `30`, `50`만 가능하며 기본값은 `10`. 이 외의 값이 들어오면 `10`으로 자동 변경 | O | `10` |
| sort | 정렬 | String | Query Parameter | 최신순/오래된순 가능, 기본값 `createdAt,DESC` | O | `createdAt,DESC` |

## Response

| key | 설명 | value 타입 | 옵션 | Nullable | 예시 |
| --- | --- | --- | --- | --- | --- |
| serviceResultId | 서비스 수행 결과 ID | UUID | - | X | `b2c3d4e5-1234-5678-9abc-def012345678` |
| startedAt | 시작 일시 | LocalDateTime | - | X | `2026-09-01T09:00:00` |
| finishedAt | 종료 일시 | LocalDateTime | - | X | `2026-09-01T10:00:00` |

## Status

| status | response content |
| --- | --- |
| `200` | 조회 성공 (없을 시 빈 배열 반환) |
